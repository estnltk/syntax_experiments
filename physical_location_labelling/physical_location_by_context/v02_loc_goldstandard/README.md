##v02 - creating a gold standard

Creating, storing and analysing a manually annotated gold standard of 1000 nominal adverbials in spatial cases. Used in v03 as test material to find how good LLM models are at annotating physical locations.

* **base_data**: raw file of 1000 adverbials with phrases for annotating
* **code**: jupyter notebooks for creating a random sample to annotate, adding sentences to it and analysing the completed annotation
* **documentation**: annotation guidelines and oddities
* **results**: final goldstandard annotation files
