Hoverplots that show how much a verb-case pattern prefers obliques that are locations. Redone with new revised annotation. Colored by how many senses the verb has in the Estonian Wordnet (if not stated otherwise).

* *location_all_colorless.html*: No Wordnet mapping. Includes all verbs.
* ***location_all_redline.html***: Includes all verbs. Drawn red line at the 80:20 location ratio. Best figure for viewing.
* *location_wordnet_redline.html*: Only includes verbs that are in the Estonian Wordnet. Drawn red line at the 80:20 location ratio.
