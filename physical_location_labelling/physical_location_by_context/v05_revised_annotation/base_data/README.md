Has revised wordlists for various semantic types. All lists have been extracted from the Institute of Estonian Language's lexicographic database [Ekilex] (https://github.com/keeleinstituut/ekilex) by combining various semantic types into larger, more general ones. Version 05 removed some semantic types that were combined and added some new ones.

* *v05_wordlists_advmod*: lists of adverbs for various semantic types
* *v05_wordlists_obl*: lists of nouns for various semantic types. 
* *v05_ekilex_semtype_combinations.md*: what ekilex semantic tags were combined to make more general tags
