* *environment_v03.yml*: anaconda environment file with all packages and versions used in this code
* *v03_gpt_annotation.ipynb*: annotates 1000 words with GPT as physical locations (LOC) or something else (NONE)
* *v03_gpt_results.ipynb*: compares GPT output with the gold standard. Calculates how well GPT annotates physical locations.
* *v03_normalize_gpt_output.ipynb*: removes inconsistencies (i.e. excessive quotation marks) from GPT annotation output
