* *gpt_10.csv*: 10 sentences and words in those sentences for preliminary prompt and model tests
* *gpt_1000.csv*: 1000 sentences and words in those sentences from the gold standard. Used to evaluate how well GPT annotates physical locations.
* *prompt_english.txt*: English translated version of *prompt_short_est.txt*
* *prompt_long_est.txt*: prompt used for preliminary testing of how well different GPT models annotate physical locations. More detailed than the prompt used for large scale annotation.
* *prompt_short_est.txt*: prompt used to annotate physical locations in *gpt_test_1000.csv*. Prompt is in Estonian.
