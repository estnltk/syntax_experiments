Has wordlists for various semantic types. All lists have been extracted from the Institute of Estonian Language's lexicographic database [Ekilex] (https://github.com/keeleinstituut/ekilex) by combining various semantic types into larger, more general ones.

* *documentation*: descriptions of semantic types in the EKILEX database and how they were combined
* *v04_wordlists_advmod*: lists of adverbs for various semantic types
* *v04_wordlists_obl*: lists of nouns for various semantic types.
