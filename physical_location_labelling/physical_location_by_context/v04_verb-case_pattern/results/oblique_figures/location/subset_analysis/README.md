Hoverplots that show how much a verb-case pattern prefers obliques that are locations. 

* *scatter_w_lines*: original article hoverplot with additional lines to mark quality
* *scatter_w_lines_ilustatud*: same quality lines but smoothed out by picking lower points
* *scatter_w_lines_multi1*: +-1 for both values (if +1 for positive count then -1 for negative counts)
* *scatter_w_lines_multi2*: +-1 for positive counts
