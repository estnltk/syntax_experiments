Hoverplots that show how much a verb-case pattern prefers obliques that are locations. Colored by how many senses the verb has in the Estonian Wordnet (if not stated otherwise).

* *in_article*: figures used in article ["Automatic Semantic Tagging of Estonian Spatial Adverbials for Valency Pattern Mining"](https://doi.org/10.1007/978-3-032-02551-7_15)
* *location_all_colorless.html*: No Wordnet mapping. Includes all verbs.
* ***location_all_redline.html***: Includes all verbs. Drawn red line at the 80:20 location ratio. Best figure for viewing.
* *location_wordnet_redline.html*: Only includes verbs that are in the Estonian Wordnet. Drawn red line at the 80:20 location ratio.
