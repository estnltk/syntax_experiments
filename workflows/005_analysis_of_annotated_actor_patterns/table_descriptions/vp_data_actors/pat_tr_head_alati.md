# Description of pat_tr_head table

The table contains verb patterns that were annotated as isikumäärus = 'alati'. 

It is a temporary table in the process of filtering verb patterns. It is a join between pattern and transaction_head table.

| Column name | Description | Example
|---|---|---|
|pat_id| pattern ID in table patterns_actors_len1_alati | 179
|head_id |  id in the transaction_head table| 8
|verb_word |	main verb | võtma 
|verb_compound| verb compound| ära 
|phrase_nr| phrase number | 1
|phrase_case	| case of the main word that is tied to the verb | abl
|pat_deprel | deprel of the word related to the verb | obl
