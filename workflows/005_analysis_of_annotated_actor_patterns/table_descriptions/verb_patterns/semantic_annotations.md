# Description of semantic_annotations table

The table contains semantic role and certainty for patterns. 

| Column name | Description | Example
|---|---|---|
|pattern_id| pattern ID | 9
|phrase_nr| phrase number | 1
|semantic_role| indicates if verb is related to actor, location or other | isik
|certainty| indicates how ofter verb is related to semantic role (alati, vahel, mitte kunagi) | vahel
