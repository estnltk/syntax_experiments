# Description of patterns table

The table contains all annotated verb patterns. 

| Column name | Description | Example
|---|---|---|
|pat_id| pattern ID | 9
|pattern| full pattern as a string| võtma ära kellelt/millelt  
|phrase_case	| case of the main word that is tied to the verb | abl
|verb_word |	main verb | võtma 
|verb compound| verb compound| ära 
|phrase_nr| phrase number | 1
|deprel	| deprel of the words that would be associated withe the pattern | obl
