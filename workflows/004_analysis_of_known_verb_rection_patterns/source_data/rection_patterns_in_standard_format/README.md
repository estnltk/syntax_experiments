## Verb rection patterns in standard format

Selles kaustas on [EKI rektsioonimustrite fail](https://github.com/estnltk/syntax_experiments/blob/verb_templates/workflows/004_analysis_of_known_verb_rection_patterns/source_data/12_eesti_ilmik_rektsiooniga_linkideta.csv) lahtipakitud kujul.
Lahtipakitud formaat võimaldab teha kiiret matchingut transaktsioonide vastu.

- `verb_patterns_len1_new.csv` sisaldab üheliikmelisi verbimustreid andmebaasi üleviimiseks sobival kujul (*compound part* esituses pole veel parandusi sisse viidud)
- `verb_patterns_len2_new.csv` sisaldab kaheliikmelisi verbimustreid andmebaasi üleviimiseks sobival kujul (*compound part* esituses pole veel parandusi sisse viidud)
- `verb_patterns_len1_new_correct.csv` sisaldab üheliikmelisi verbimustreid andmebaasi üleviimiseks sobival kujul. Sisse on viidud parandused *compound part* esitusviisis
- `verb_patterns_len2_new_correct.csv` sisaldab kaheliikmelisi verbimustreid andmebaasi üleviimiseks sobival kujul. Sisse on viidud parandused *compound part* esitusviisis
