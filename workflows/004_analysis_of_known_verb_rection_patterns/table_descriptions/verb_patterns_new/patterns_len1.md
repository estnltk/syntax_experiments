# Description of patterns_len1 table

The table contains information about one-member verb rection patterns.

| Column name | Description | Example
|---|---|---|
|ID| Pattern ID | 80
|word| Full pattern as a string | arveid klaarima
|government| phrase connected to main verb | kellega
|verb_word| (main) verb | klaarima
|compound_prt1| first compound part | arveid
|compound_prt2| second compound part | ''
|compound_prt3| third compound part | ''
|full_pattern| government where question words have been changed to cases | kom
|w_case| Grammatical case of main phrase word | kom
|adp| Phrase adposition | gen
|verb| Phrase infinitive | ''
|other| Phrase word that does not fit into any of the other categories | ''
|phrase_nr| Phrase number. If pattern consists on a singular phrase, the number will be 1. If pattern consists of two phrases, the number of the first phrase will be 1 and the number of the second one will be 2 | 1
