# Description of patterns_len2 table

The table contains information about two-member verb rection patterns.

| Column name | Description | Example
|---|---|---|
|ID| Pattern ID | 17
|word| verb (compound) as a string | küsima
|government| phrase connected to main verb | kelle käest + mida*
|verb_word| (main) verb | küsima
|compound_prt1| first compound part | ''
|compound_prt2| second compound part | ''
|compound_prt3| third compound part | ''
|full_pattern| government where question words have been changed to cases | gen käest + part
|member1_case| Grammatical case of main first phrase word | gen
|member1_adp| First phrase adposition | käest
|member1_other| First phrase word that does not fit into any of the other categories | ''
|member2_case| Grammatical case of main second phrase word | part
|member2_adp| Second phrase adposition | ''
|member2_verb| Second phrase infinitive | ''
|member2_other| Second phrase word that does not fit into any of the other categories | ''
