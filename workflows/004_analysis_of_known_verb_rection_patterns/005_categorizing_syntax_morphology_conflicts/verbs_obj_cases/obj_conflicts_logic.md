## Object conflicts logic

1. Any *olema*-verb construction can't have grammatical object
2. Other verbs that can't have a grammatical object, specified by a list
3. Grammatical object in singular nominative case can only occur with verb in imperative mood
4. Grammatical object's possible part-of-speeches are:
 - S or H (most common)
 - P
 - Y
 - A or N (less common)
