# Description of patterns_tr_head table

Temporary (?) table for verb patterns and semantic role. Adds transaction_head.id to patterns_role table.

| Column name | Description | Example
|---|---|---|
|head_id| transaction head id | 12
|pat_id| pattern ID in table patterns_actors_len1_alati | 9
|verb_word |	main verb | võtma 
|verb_compound| verb compound| ära 
|phrase_nr| phrase number | 1
|phrase_case	| case of the main word that is tied to the verb | abl
|pat_deprel | deprel of the word related to the verb | obl
|role| role and certainty| isik_alati
