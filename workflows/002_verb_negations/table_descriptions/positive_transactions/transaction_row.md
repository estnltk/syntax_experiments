## Description of transaction_row table

The table contains filtered copy of transaction_row table containing only non-negated transactions from transactions database (v32).

[[Descriptions of transaction tables](https://github.com/estnltk/syntax_experiments/tree/verb_templates/workflows/001_verb_transactions/v33/table_descriptions)]


## Additional information

-  Due to some *transaction_head* table verbs that are negated but have not been marked as such in *feats* column, some phrases containing a negation word still occur in this *transaction_row* table.
