### Table descriptions

Loodud andmebaasitabelite dokumentatsioon andmebaaside kaupa.

- `/filtered` hakkab sisaldama dokumentatsiooni transaktsioonide filtreerimise käigus tekkinud andmebaaside `v32_data_filtered.db`, `v32_data_filtered_neg.db` ja `v32_data_filtered_no_neg.db` tabelite kohta
- `/neg_tables` sisaldab dokumentatsiooni eitustabelite loomise käigus tekkinud andmebaasi `neg_tables.db` tabelite kohta
- `/negations` sisaldab dokumentatsiooni eitusmustrite põhjal algsete transaktsioonide hulgast eraldatud eitust sisaldavate transaktsioonide indeksitabeli kohta andmebaasis `negations.db`.
