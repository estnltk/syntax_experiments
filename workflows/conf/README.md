
### Example conf file to run py files.

**Currently, every py file has to be run separately! **

Examples how to run in 'workflows' folder:

>> python3 prep/02_syntax_validation/syntax_validation_rules.py --conf conf/conf_example.ini

>> python3 verb_case_pattern_annotation/05_spatial_obl_verbcase_merge_confidence_data.py --conf conf/conf_example.ini

To run for example ELT, A and S tags then "target_tag" and "other_tags" need to be changed accordingly.
