# Various benchmarks for locative adverbials

There are three ways how one can group locative adverbials:

* based on semantic categories adverbials represent (e.g. geograhic locations, physical objects, living entities)
* based on semantic roles adverbials take (e.g. source, destination, path)
* based on subcategorisation of adverbials (e.g. lative and separative locative adverbials) 

In the benchmarks we consider only the first two groupings as subcategrisatioin of adverbials almost completely 
matches categorisation based on semantic roles. We build benchmarks for the first two categorisations as they 
reveal different types of strengths and weaknesses of automatic annotators. 
  
Annotation guidelines are given separately for both categorisations in appropriate subdirectories.
The corresponding test sets can be considered as extensive examples for the annotation guidelines.
Although they are chosen from a random subset of sentences, there is a mild selection bias as one of the aims 
is to clarify and resolve ambiguouties in the annotation guidlines.

The benchmark is not meant for estimating absolute performance. Rather its aim is to capture progress or 
regression in certain subdomains during the iterative development. 
Test sets are built by incrementally adding positive and negative examples.
Each file contains up to 100 test cases.
