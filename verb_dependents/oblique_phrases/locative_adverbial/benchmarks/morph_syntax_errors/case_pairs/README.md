# Käändepaaride analüüs

Vaadatud on kohakäänete paare (v.a sama käände paarid nt adit+adit).

Üks kääne paarist peab vastama peasõna käändele ning teine kääne vastab tekstis vahetult eelnevale/järgnevale sõnale.

Eesmärk on näha, kas käändepaar saab esineda koht+koht kontekstis (nt Tallinnasse restorani) või on tegu probleemse juhuga, kus üks sõna on asukoht, kui teine sõna on muus rollis (nt kaitseliitlasest mehelt).

Paarid on jagatud gruppidesse järgnevalt:

- OK - käändepaar esineb koht+koht kontekstis ja ei tundu olevat palju probleeme

- KAHTLANE - käändepaar esineb koht+koht kontekstis aga esineb ka muid juhte 

- PIGEM MITTE - käändepaar ei esine väga tihti koht+koht kontekstis

- Näited puudusid

Näited on kujul:  verb+peasõna(peasõna kääne) ja lauses on märgitud **peasõna** ja *teine kohakäändes sõna*.
