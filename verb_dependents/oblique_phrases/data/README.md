## Datasets

In this context "category" refers to verb phrases that are semantically in one group (almost always and almost never locations). 

- n80 - predominantly locative 
- n50 - sometimes locations
- n20 - almost never locations

The files contain sentences from different verb-case groups (category).

Each filename consist of category + manner of sampling. 

Manner of sampling is for example: all verbs in the category, for each 500 unique lemmas.

**n80_.._v01.csv file has faulty data. In the future, use n80_..._v02 file.**


*_sample* at the end of filename means a sample of 100 rows from the dataset file.
